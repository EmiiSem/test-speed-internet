# Скорость скачивания

Консольный скрипт на Python. Десять раз подряд скачивает указанный адрес, каждый раз дожидается полного ответа, затем печатает среднее время запроса, общий объём данных и скорость скачивания.

Зависимостей нет: достаточно Python 3.9+ и стандартной библиотеки.

## Запуск

```bash
python download_speed.py "https://images.hdqwalls.com/download/view-from-my-home-12k-8z-7680x4320.jpg"
```

Необязательный таймаут одного запроса, в секундах (по умолчанию 60):

```bash
python download_speed.py "https://speed.cloudflare.com/__down?bytes=1000000" --timeout 30
```

Если запрос не удался, скрипт печатает ошибку в stderr и завершается с кодом 1. Успешный прогон завершается с кодом 0.

## Единицы

| Величина | Единица | Как считается |
| --- | --- | --- |
| Время запроса | секунды (с) | от начала запроса до полного чтения тела ответа |
| Среднее время | секунды (с) | сумма десяти длительностей / 10 |
| Объём | байты и мегабайты (МБ) | сумма размеров тел ответов; 1 МБ = 1 000 000 байт |
| Скорость | мегабиты в секунду (Мбит/с) | (общий объём в байтах × 8) / суммарное время / 1 000 000 |

Скорость считается по полезной нагрузке: размеру тел ответов за суммарное время десяти запросов, включая установку соединения. Заголовки HTTP в объём не входят.
